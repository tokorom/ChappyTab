# ChappyTab

ChatGPT用のmacOSタブブラウザ。macOS 14以降、Xcodeで `ChappyTab.xcodeproj` を開いて実行します。

- 起動時と「新しいタブ」は `https://chatgpt.com/` を表示します。
- タブごとにWKWebViewを保持し、切り替えてもページや入力内容を維持します。
- 全タブで `WKWebsiteDataStore.default()` を共有します。Cookie・Webストレージはアプリ専用の永続領域に保存します。SafariやChromeのログイン情報とは別です。
- 認証ページのポップアップは、渡されたWebKit設定を引き継いだタブとして開きます。
- 最後のタブを閉じると、新しいChatGPTタブを表示します。左右移動は端で循環します。
- 再起動時は新しいChatGPTタブから開始します（開いていたタブの復元は行いません）。

## ショートカット

| 操作 | 初期設定 |
| --- | --- |
| 新しいタブ | ⌘T |
| タブを閉じる | ⌘W |
| 右のタブ | ⌃N |
| 左のタブ | ⌃P |
| 設定 | ⌘, |

設定画面の一覧で操作をクリックし、ダイアログで実際にショートカットキーを押して保存します。Command・Control・Optionのいずれかと半角英数字を組み合わせられます。重複と主な標準ショートカットへの上書きを防ぎ、変更をUserDefaultsへ保存します。既存のカスタム設定は維持され、「初期設定に戻す」で新しいデフォルトを適用できます。

設定画面はサイドバーの「キーボードショートカット」と「About」で切り替えます。Aboutにはアプリアイコン、アプリ名、バージョンとビルド番号、GitHubへのリンクを表示します。バージョン情報はアプリ本体から取得するため、リリース時のバージョンに追従します。

## ダウンロード

WebKitのダウンロード指定（HTMLのdownload属性、Blob・Data URL、添付ファイル応答、表示できないファイル形式）を受け取り、保存先を選ぶダイアログを表示します。認証情報はWebKitのセッションをそのまま使用します。保存のキャンセルに対応し、既存ファイルの置き換えは転送成功後に行います。タブを閉じても開始済みのダウンロードは継続します（アプリ終了後の再開には未対応）。

## コードブロックの表示

ChatGPTのコードブロックで、`corner-shape: superellipse(1.1)` とクリッピングの組み合わせにより、WebKitでは背景だけが表示される場合があります。`chatgpt.com` と `chat.openai.com` のメインページ内の `[data-code-block]` に `corner-shape: round` を適用して回避します。角の形状だけを変更し、コード本文・色分け・スクロール・コピーボタンはページの実装を使用します。

ローカルHTMLを使ったWKWebView上の確認は、次のコマンドで実行できます。

```sh
swiftc -parse-as-library ChappyTab/ChatGPTWebCompatibility.swift tests/ChatGPTWebCompatibilityTests.swift -o /tmp/chappytab-web-tests
/tmp/chappytab-web-tests
```

描画不具合の確認には実際の会話も使用します。コードと言語名・ボタンが表示されること、ブロック内のスクロールとコピー、ページの再読み込みとタブ切り替え後も表示されることを確認してください。

## ログインの確認

1. アプリ内でChatGPTにサインインする。
2. ⌘Tで新しいタブを作り、ログイン状態を確認する。
3. ⌘Qで終了して起動し直し、ログイン状態を確認する。
4. 会話を別々のタブで開き、切り替え後もページ・入力が保持されることを確認する。
5. 設定でキーを変更し、Webページ入力中にも反映されることを確認する。

永続ストレージは再起動後も保持されますが、認証サービスによるセッション失効や、埋め込みブラウザを許可しないログイン方式では再認証や別の認証方式が必要な場合があります。外部ブラウザでログインしても、そのCookieは本アプリには移りません。実アカウントでのサインインは手動確認が必要です。

## ビルド

```sh
xcodebuild -project ChappyTab.xcodeproj -scheme ChappyTab -configuration Debug CODE_SIGNING_ALLOWED=NO build
```
